## ✦ Overview

**Inchara Holidays** is a bespoke, responsive web application designed for discovering and curating experiential journeys across South India, Karnataka's Western Ghats (Malenadu), coastal circuits, and global getaways.

Built with an authentic **South Indian Heritage design language**, the application blends royal Mysore aesthetics, Kaavi terracotta tones, and traditional threshold art into a smooth modern web experience.

---

## ✦ Authentic Cultural Design Factors

- **Royal Ambari Elephant (ಅಂಬಾರಿ ಆನೆ)**: Celebrating the grandeur of Mysore Dasara with howdah iconography.
- **Dravidian Temple Gopuram (ಗೋಪುರ)**: Sacred architecture guiding heritage routes and cultural circuits.
- **Sacred Lotus (ಕಮಲ / Padma)**: Clean, serene badge elements and cultural guarantees.
- **Hanging Temple Bell (ಘಂಟೆ)**: Symbolizing learning, educational expeditions, and peaceful sanctuaries.
- **Floral Torana Garland (ತೋರಣ)**: Traditional floral entrance garlands adorning section headings.
- **Ribbed Banana Leaf (ಬಾಳೆ ಎಲೆ)**: Representing traditional South Indian culinary feasts and catering hospitality.
- **Kaavi Terracotta (`#9E3D28`) & Sikku Kolam (ರಂಗೋಲಿ)**: Authentic threshold knot mandalas and continuous border ribbons woven into modal backdrops and section accents.

---

## ✦ Key Features

- **Full Bilingual Support**: Seamless one-click switching between **ಕನ್ನಡ (Kannada)** and **English**.
- **Interactive Multi-Step Trip Planner**: 8-step conversational inquiry modal covering scope, dates, styles, budget tiers, and direct WhatsApp / brief generation.
- **Destination Discovery**: Comprehensive regional showcases (Coorg, Hampi, Gokarna, Kabini, Chikmagalur, and global circuits) featuring bespoke imagery, curated highlights, Kannada travel phrasebook, and cultural etiquette guides.
- **Specialized Service Portals**:
  - **Corporate Events & Executive Retreats**
  - **Traditional Catering & Plantain Leaf Hospitality**
  - **Educational Expeditions & Student Heritage Tours**
  - **General Inquiries & Travel Guidance**
- **Accessible & Responsive UX**: Full keyboard accessibility (<kbd>Esc</kbd> to close any dialog), isolated hit targets, mobile slide-up sheets, and optional ambient custom cursor.

## ✦ Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/Srinidhi-070/Inchara-Holidays.git

# Navigate into project directory
cd Inchara-Holidays

# Install dependencies
npm install
```

### Development

```bash
# Run local Vite development server
npm run dev
```

### Production Build

```bash
# Typecheck & build optimized production bundle
npm run build
```
